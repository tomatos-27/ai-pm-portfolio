# 石梦瑶｜AI 产品经理 Portfolio V0.1 Public Draft

面向招聘经理的静态中文作品集。首页优先呈现岗位定位、关键证据和项目入口；两个已完成项目分别有一页详情。旗舰 AI 项目仅显示 `In Progress`。

## 文件结构

```text
index.html                     首页
cases/sales-enablement.html    销售赋能项目 Case Study
cases/ai-product-lab.html      AI Product Lab 总详情页
assets/css/styles.css          全站样式与响应式布局
```

所有页面均为静态 HTML，不依赖构建工具或 JavaScript。直接打开 `index.html` 即可浏览。
