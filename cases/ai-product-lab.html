01 / PURPOSE

理解机制，再做产品选择

AI Product Lab 用小范围实践拆解 AI 产品常见机制。它服务于产品工作中的问题：模型输出如何被系统使用？外部知识与工具何时介入？工作流与 Agent 如何选择？效果如何评估并防止回归？

实践重点

关注 AI 产品的可用性、边界与验证方式，而不是把代码量作为成果。

03 / PRACTICE THEMES

已完成实践覆盖的主题

根据目前提供的信息，系列实践包含以下主题。它们在产品设计中分别对应输出、连接、知识、行动、编排与验证。

01

Structured JSON

关注模型输出如何形成可被后续系统消费的结构。

02

API 调用链与错误处理

关注一次模型调用如何进入产品流程，以及失败时如何处理。

03

RAG

关注外部知识如何参与回答，以及信息来源与回答质量。

04

Tool Calling

关注模型何时需要调用工具，以及工具结果如何回到流程。

05

Workflow vs Agent

关注固定流程与自主决策流程的适用边界。

06

Evaluation / Regression

关注如何设定评测与回归检查，让产品改动可验证。

04 / PRODUCT JUDGMENT

把技术机制转成产品问题

输出

结果需要怎样的结构，才能进入真实业务流程？

知识

任务是否需要外部资料？如何判断检索是否有帮助？

行动

何时需要调用工具，何时只需要清晰的固定流程？

验证

用什么 Baseline、评测和回归检查判断方案是否更好？
